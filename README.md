## Overview

Shazee AI Command Center is an online AI assistant portfolio project designed to showcase modern AI app development skills. It includes real AI chat, voice input, voice output, animated 3D visuals, responsive design, and a professional portfolio showcase.

## Features

- Real AI chat powered by Groq API
- Secure Next.js API route for AI requests
- Voice input using browser speech recognition
- Voice output using browser speech synthesis
- Animated 3D Jarvis-style globe
- Responsive design for laptop, mobile, and tablet
- PWA-ready setup
- Portfolio sections for skills, projects, and contact
- Deployed online with Vercel

## Tech Stack

- Next.js

This project was built as a portfolio app to demonstrate AI integration, futuristic UI design, voice interaction, frontend development, backend API routing, and live deployment.
